# LAMMPS include files

Add simulation-ready LAMMPS `pair_style` and `pair_coeff` include files here.

Recommended naming:

```text
licl_ar_rim_real_units.in.settings
licl_xe_rim_real_units.in.settings
kcl_ar_rim_real_units.in.settings
kcl_xe_rim_real_units.in.settings
```

Keep the source parameter tables in `force_fields/` and use these include files only for the final converted values used by LAMMPS.
