# Data

Use this directory for data needed to reproduce figures and tables.

Suggested organization:

- `raw/`: raw or lightly processed output files that are small enough for GitHub.
- `processed/`: cleaned PMF, RDF, MSD, and diffusion data.
- `figure_data/`: final numerical data plotted in each manuscript figure.

For large raw trajectories, add a row to `metadata/file_manifest.csv` that records where the data are archived.
